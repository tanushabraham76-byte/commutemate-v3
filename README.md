# CommuteMate V3

## About the Project
CommuteMate is a student ride-sharing platform prototype
designed to help commuters find and share rides.

The goal is to make daily travel more affordable,
convenient, and accessible.

## Main Features
- Search rides by starting point and destination.
- Select a travel date and manually enter a time.
- View available sample rides and compare prices.
- Book rides for yourself or someone else.
- Choose cash or online payment (demo only).
- View and cancel bookings.

## Technologies Used
- HTML
- CSS
- JavaScript
